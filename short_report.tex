\begin{abstract}
Prior Dempster-Shafer gradient-descent classifiers primarily study evidential mass learning and prediction from a supplied rule representation \cite{penafiel2020,tarkhanyan2025}. This paper evaluates DSGD-Auto under a frozen induced-ruleset protocol: repository-specific FOIL-style and RIPPER-style inducers first emit the rule set, and DSGD then learns evidential masses without adding, removing, or rewriting rules. Experiments use one fixed 80/20 train/test split per dataset, five training seeds per induced ruleset, and deterministic non-DSGD rule baselines on the same split. Among rule-based variants, learned Dempster fusion is the best Accuracy variant on 6/9 datasets and the best Macro-F1 variant on 6/9 datasets, while Random Forest remains stronger or tied against the best rule model on most datasets. Code and artifacts: \url{https://github.com/SargisVardanian/DST}.
\end{abstract}

\begin{IEEEkeywords}
evidential classification, Dempster-Shafer theory, rule induction, FOIL, RIPPER, tabular classification
\end{IEEEkeywords}

\section{Introduction}
Rule-based classification represents prediction with explicit if-then conditions rather than opaque scores. FOIL and RIPPER are supervised rule-induction methods that learn such rules from labeled data \cite{quinlan1990,cohen1995}. FOIL grows class-directed rules by adding informative literals, while RIPPER learns ordered rules and prunes them to improve generalization.

On top of such rules, Dempster-Shafer theory provides a way to represent both class support and residual uncertainty \cite{dempster1968,shafer1976}. In the present implementation, each rule is parameterized by a mass vector over the selected focal elements: the $C$ class singletons and the explicit ignorance state $\Omega$. Following DSGD/DSGD++ \cite{penafiel2020,tarkhanyan2025}, the model learns per-rule mass logits under this experimental parameterization, fuses the masses of the fired rules, and converts the fused mass into class probabilities through the pignistic transform \cite{smets1994}.

The protocol studied here is deliberately narrow. We use a frozen induced ruleset: rule induction is completed before mass learning, and the subsequent DSGD stage does not add, remove, or rewrite rules. The FOIL-style and RIPPER-style inducers used here are repository-specific implementations inspired by the classical algorithms, with project-specific preprocessing, covering, pruning, and rule-pool shaping choices. They should therefore be read as induced-rule pipelines around FOIL/RIPPER ideas, not as unmodified textbook baselines.

The empirical question is controlled and specific. We compare several aggregation rules on the same induced rulesets and include Random Forest as an external non-rule reference \cite{breiman2001}. The goal is to ask how much the final prediction changes when the rule pool is fixed and only the aggregation mechanism changes.

\section{Experimental Setup}
An earlier static variant assembled short conjunctions from feature-level literals; the present report focuses on supervised FOIL-style and RIPPER-style induced rulesets. For each dataset, the current benchmark uses one stratified 80/20 train/test split with split seed 42. Rule induction is run on the training split, producing a frozen ruleset. DSGD mass learning is then repeated over seeds 42--46, while the ordered-rule, first-hit fixed-confidence, and weighted rule-vote baselines are deterministic once the induced ruleset is fixed. Random Forest is trained under the same split protocol with 400 trees and the matching run seed. No cross-validation or repeated train/test resampling is claimed in this snapshot.

Dataset loading drops rows with missing values, removes ID-like columns, factorizes labels in sorted class order, and integer-encodes categorical features while retaining decoders for rule captions. These preprocessing steps are applied by the repository loader before the fixed split. The tabular datasets are drawn from standard public benchmark sources, primarily UCI/OpenML where applicable \cite{uci2017,openml2013}; Dry Bean and Gas Sensor Drift use their UCI dataset entries \cite{drybean2020,gasdrift2012}. The exact CSVs used by this run are the local artifacts named in Table~\ref{tab:dataset_snapshot}.

The benchmark compares several aggregation schemes on the same frozen induced ruleset. Hard-rule baselines are deterministic rule-only predictors that use the induced rules directly, without learned evidential mass parameters. Let $\mathcal{A}(x)=\{r_1,\dots,r_m\}$ denote the fired rules for sample $x$ in the order emitted by the inducer after its internal covering, pruning, and pool-shaping procedure, and let $\hat{y}(r)$ be the label attached to rule $r$.

A rule fires for sample $x$ when $x$ satisfies every literal in the rule antecedent. Ties in argmax-based predictors follow the deterministic array order used by NumPy/PyTorch, i.e., the lowest encoded class index among tied maxima.

The ordered-rule baseline predicts from the first activated rule in this emitted order,
\[
\hat{y}_{\mathrm{native}}(x)=\hat{y}(r_1).
\]
If no rule fires, the implementation applies its default-class fallback.

The first-hit fixed-confidence baseline uses the same first activated rule but assigns a fixed high probability to that predicted class for probability-based metrics. In the current code path this is not a true Laplace estimate from rule support counts, so we do not use the Laplace name for the reported results:
\[
\begin{aligned}
\tilde{p}_k(x)&=
\begin{cases}
0.9/Z, & k=\hat{y}_{\mathrm{native}}(x),\\
(0.1/C)/Z, & \text{otherwise},
\end{cases}
\\
Z&=0.9+0.1(C-1)/C.
\end{aligned}
\]
If no rule fires, the first-hit predictor uses the training-split majority class as its default class.

The weighted rule-vote baseline aggregates all fired rules without learned evidential mass parameters, but each rule's vote is weighted by its training-set support and confidence. Its artifact identifier in the code and CSV files is \code{weighted\_vote}. For each rule $r$, let $s_r$ be its positive training support and let $n_r$ be the number of covered training samples outside the rule's consequent class. We define a Laplace-smoothed rule confidence
\[
q_r=\frac{s_r+1}{s_r+n_r+C},
\]
and a support-scaled vote weight
\[
w_r=q_r\log(1+s_r).
\]
The class scores are then
\[
\begin{aligned}
s_k(x)&=\sum_{r\in\mathcal{A}(x)} w_r\mathbf{1}\{\hat{y}(r)=k\},\\
\hat{y}_{\mathrm{wv}}(x)&=\arg\max_k s_k(x),
\end{aligned}
\]
and for probability metrics the normalized weighted scores are used, $p_k(x)=s_k(x)/\sum_j s_j(x)$, when at least one rule fires. Thus a high-support, high-confidence rule contributes more than a low-support or low-confidence rule, while no learned masses are introduced in this baseline. If no rule fires, the vote path returns a vacuous evidence state for probability metrics and the label wrapper uses the training-split majority-class fallback.

For learned Dempster fusion, each fired rule carries a learned mass vector
\[
m_r=[m_r(\{1\}),\dots,m_r(\{C\}),m_r(\Omega)].
\]
For two mass functions $m_1,m_2$, Dempster's normalized combination is
\[
(m_1\oplus m_2)(A)=
\frac{\sum_{B\cap D=A}m_1(B)m_2(D)}{1-\kappa},\quad A\neq\emptyset,
\]
where $\kappa=\sum_{B\cap D=\emptyset}m_1(B)m_2(D)$ is the conflict mass. Repeated fusion over fired rules gives
\[
m^\star(x)=\bigoplus_{r\in\mathcal{A}(x)} m_r,
\]
and the final class probabilities are obtained by the pignistic transform
\[
\begin{aligned}
\mathrm{BetP}_k(x) &= m^\star(\{k\})+\frac{m^\star(\Omega)}{C},\\
\hat{y}_{\mathrm{dsgd}}(x) &= \arg\max_k \mathrm{BetP}_k(x).
\end{aligned}
\]

In the tables, ``FOIL + learned Dempster fusion'' and ``RIPPER + learned Dempster fusion'' are the DSGD-Auto variants; ordered-rule, first-hit fixed-confidence, and weighted rule-vote are non-learned aggregation baselines over the same induced rulesets.

The comparison therefore isolates the effect of aggregation while keeping the underlying induced rules fixed. The FOIL-style and RIPPER-style components are not claimed as unmodified reference implementations of Quinlan's FOIL or Cohen's RIPPER. They reuse the classical grow/cover/prune intuition but include repository-level preprocessing, candidate literal generation, duplicate filtering, emitted ordering, and rule-pool shaping. Therefore the empirical comparison is between aggregation mechanisms over the induced rulesets produced by this repository, not a benchmark of canonical FOIL versus canonical RIPPER.

We report both mean activated-rule ignorance and combined ignorance after fusion. Here \code{unc\_mean} is the per-sample average $\Omega$ mass over activated rules, with no-fire samples assigned full ignorance, and \code{unc\_comb} is the fused $\Omega$ mass after Dempster aggregation. Uncertainty metrics are reported only for methods that produce an evidential mass function with an explicit $\Omega$ component. Non-evidential hard-rule baselines and Random Forest do not produce a directly comparable $\Omega$ mass, so their uncertainty entries are marked as not applicable. Expected calibration error uses 15 equal-width confidence bins \cite{guo2017}.

Across the nine datasets, learned Dempster fusion is the best rule-based Accuracy variant on 6/9 datasets and the best rule-based Macro-F1 variant on 7/9 datasets. Against the matching weighted rule-vote baseline, learned Dempster improves Accuracy on 6/9 RIPPER rows and 5/9 FOIL rows, and improves Macro-F1 on 8/9 RIPPER rows and 5/9 FOIL rows. These paired counts are descriptive; with only nine datasets they should not be read as conclusive significance evidence.

Random Forest remains the stronger pure predictive baseline on most datasets: it is stronger than or tied with the best rule-based row on 9/9 datasets for both Accuracy and Macro-F1. The motivation for DSGD-Auto is therefore not raw accuracy dominance over Random Forest, but the combination of competitive rule-based accuracy, explicit fired-rule structure, learned uncertainty mass, and inspectable sample-level explanations.

Calibration remains a limitation. Lower NLL does not coincide with better calibration here: in this benchmark snapshot, learned Dempster fusion often improves NLL relative to the weighted rule-vote baseline, while ECE remains worse for both FOIL and RIPPER. After aligning the learned model's training and reporting readout to the standard pignistic redistribution $m^\star(\Omega)/C$, the ECE gap remains dataset-sensitive rather than disappearing. The large NLL gap between weighted rule-vote and learned Dempster fusion should not be read as a proportional accuracy gain. The weighted-vote baseline produces rule-quality-weighted probability vectors from normalized class scores, so NLL is sensitive to score sharpness even when Accuracy/Macro-F1 changes are small.

\subsubsection{Worked Example}
One inspection export from the adult/RIPPER benchmark split shows how the model turns a set of active rules into one readable inspection summary.\footnote{Inspection artifact: \code{sample\_13131\_test\_dempster.md} under \code{src/results/raw\_runs/inspection/adult/RIPPER/}.} For this sample, five rules fire:
\begin{itemize}
\item \code{R84: age > 53 \& capital.gain < 5013 \& education == HS-grad \& ...}, $m=[0.7718, 0.0000, 0.2282]$
\item \code{R199: age > 30 \& fnlwgt > 1.304e+05 \& occupation == Prof-specialty \& ...}, $m=[0.0000, 0.4473, 0.5527]$
\item \code{R164: age > 31 \& hours.per.week > 32 \& occupation == Prof-specialty \& ...}, $m=[0.0000, 0.3068, 0.6932]$
\item \code{R119: age > 57 \& capital.gain < 5013 \& hours.per.week < 42 \& ...}, $m=[0.2993, 0.0000, 0.7007]$
\item \code{R169: marital.status == Married-civ-spouse}, $m=[0.1974, 0.0000, 0.8026]$
\end{itemize}

These five rule masses are fused for prediction. The combined explanation shown below is not a sixth learned rule; it is a post-hoc readability summary that merges repeated or compatible literals from positively contributing activated rules and assigns display weights to the resulting literals. For a fired rule $r$, the mass-mode display contribution is positive when the rule supports the predicted class and negative when the largest opposing singleton dominates; the positive contribution is divided by the number of literals in $r$. Compatible literal contributions are merged, and each merged literal receives normalized display weight proportional to $1-\prod_r(1-s_r)$, where $s_r$ is the contributing rule score multiplied by $(1-m_r(\Omega))$. These explanation weights are separate from the weighted rule-vote baseline, whose prediction weights are computed from support and confidence statistics. The summary is not guaranteed to be logically equivalent to the full fired-rule set. The inspection view therefore presents one weighted explanation summary:
{\scriptsize
\[
\begin{aligned}
\code{combined\_explanation} &\approx
0.150[\code{age > 57}] \\
&+0.150[32 < \code{hours.per.week} < 40] \\
&+0.145[\code{marital.status == Married-civ-spouse}] \\
&+0.130[130420 < \code{fnlwgt} < 172960] \\
&+0.116[\code{capital.gain < 5013}] + \cdots
\end{aligned}
\]
}
and the final fused output is reported as
{\small
\[
\begin{aligned}
p &= [0.7756, 0.2244],\\
m &= [0.7225, 0.1712, 0.1063].
\end{aligned}
\]
}
This reduces the sample-level display from several overlapping active rules to one combined explanation summary with explicit literal weights, together with the final class probabilities and remaining uncertainty.

\subsubsection{Hard Cases}
We also study a hard-case subset of the benchmark test split. A sample enters this subset when the fired rules show at least one difficult pattern on the same dataset/inducer ruleset. The implemented criteria are: rule-label disagreement; high simultaneous firing depth, defined as $n_{\mathrm{fired}}\geq\max(3,\lceil Q_{0.75}(n_{\mathrm{fired}})\rceil)$ within the same dataset/inducer test split; low weighted-vote margin, defined as top-1 minus top-2 weighted-vote probability at most $0.15$; minority support for the true class, where the true class has at least one fired rule but the strongest wrong class has at least one more fired rule; or the pattern ``one true rule versus many wrong rules,'' where exactly one fired rule supports the true class and at least two fired rules support a wrong class.

This subset is not a separate benchmark. It is a diagnostic slice of the same test split. The current hard-case export contains 26,928 samples across 18 dataset/inducer subsets. Learned Dempster fusion improves over weighted rule-vote on 8/18 hard-case subsets by Accuracy and 9/18 by Macro-F1, with mean deltas of +0.0024 Accuracy and +0.0080 Macro-F1. These numbers are diagnostic, not proof of systematic hard-case superiority.

\subsection{Limitations}
The current results should be read as a fixed-split, multi-seed benchmark of a frozen-rule aggregation pipeline. They do not by themselves prove split-robust superiority, rule-diversity effects, or a general interpretability advantage. Stronger claims would require repeated train/test splits, ablations of rule-pool shaping, and direct analysis of rule overlap, fired-rule counts, conflict rates, and calibration under distributional variation. We also do not include an empirical reimplementation of prior DS classifiers such as Pe\~nafiel et al.; the present comparison is restricted to aggregation variants over the repository's induced rulesets plus Random Forest as an external predictive reference.

\section{Conclusion}
On the present benchmark, learned evidential aggregation on FOIL- and RIPPER-induced rules is often competitive with simpler rule aggregation on the same rulesets.

The main positive result is that DSGD-Auto can match or improve some rule-based baselines while preserving an inspection-friendly decision structure through explicit rule masses and fusion. The main limitation is that these gains are uneven across datasets and do not translate into uniformly better calibration.

These results support benchmark-level competitiveness of evidential aggregation in the evaluated setting, while broader superiority claims would require stronger split-robust and calibration-focused validation.
